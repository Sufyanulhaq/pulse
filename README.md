# Pulse

A landing page concept for a focus-tracking app, built to explore scroll-linked motion design and animation-heavy UI work.

**[Live demo](#)** — replace with your deployed URL

## Features

- Animated hero with a scroll-linked stat panel and floating cards
- Scroll-triggered reveal sections built with [`motion`](https://motion.dev)
- Accessible motion: full `prefers-reduced-motion` support throughout
- A working waitlist form with inline validation and success state
- Fully responsive, no horizontal scroll from 375px up

## Stack

- [React 19](https://react.dev)
- [Vite](https://vitejs.dev)
- [motion](https://motion.dev) for animation

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build

```bash
npm run build
```
